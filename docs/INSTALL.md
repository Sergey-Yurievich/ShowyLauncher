# Установка ShowyLauncher

Два этапа: сначала с телевизора убирается лишнее (реклама, слежка, демо-режимы), потом ставится лаунчер, и он
становится единственным главным экраном. Всё обратимо: приложения отключаются, а не удаляются, и
`scripts/restore.sh` возвращает телевизор как было.

Можно пройти по шагам самому или поручить это Claude — см. [«С помощью Claude»](#с-помощью-claude) в конце.

## Что понадобится

- **Телевизор TCL на Google TV.** Проверено на TCL G08 «Smart TV Pro» с Google TV 12 и Google TV 14. Лаунчер встанет
  на любой Google TV / Android TV 9+, но список очистки составлен для TCL.
- **Компьютер** с macOS, Windows или Linux в той же сети, что и телевизор.
- **Showy** — через него лаунчер ищет фильмы. Есть бесплатный сервер и PRO; телевизор привязывается кодом в
  Telegram-боте [@showybot](https://t.me/showybot).
- **Плеер ViMu** — ставится на телевизор из Play Маркета, фильмы играют в нём.
- Около получаса.

## Шаг 0. Подготовка

### 0.1. ADB на компьютере

ADB — стандартная утилита Android, через неё компьютер управляет телевизором по сети.

- **macOS:** скачайте [SDK Platform-Tools для Mac](https://developer.android.com/tools/releases/platform-tools) и
  распакуйте в домашнюю папку (получится `~/platform-tools`). Или, если есть Homebrew:
  `brew install android-platform-tools`. Команды ниже вводятся в программе «Терминал».
- **Windows:** поставьте [Git for Windows](https://git-scm.com/download/win) — в нём есть **Git Bash**, все команды
  ниже вводятся в нём. Скачайте [SDK Platform-Tools для Windows](https://developer.android.com/tools/releases/platform-tools)
  и распакуйте в `C:\Users\<ваше имя>\platform-tools`.
- **Linux:** `sudo apt install adb` (или Platform-Tools с сайта выше).

Скрипты сами ищут `adb` в этих местах. Если он лежит где-то ещё, укажите путь: `ADB=/путь/к/adb scripts/...`.

### 0.2. ShowyLauncher на компьютере

На странице [репозитория](https://github.com/Sergey-Yurievich/ShowyLauncher): **Code → Download ZIP**, распакуйте.
Или `git clone https://github.com/Sergey-Yurievich/ShowyLauncher.git`.

Откройте терминал в этой папке, например:

```bash
cd ~/Downloads/ShowyLauncher
```

Все команды ниже запускаются отсюда.

### 0.3. Режим разработчика на телевизоре

1. **Настройки → Система → Об устройстве**, пункт **«Сборка ОС Android TV»**: нажмите OK на пульте 7 раз, пока не
   появится «Вы стали разработчиком».
2. **Настройки → Система → Для разработчиков**: включите **«Отладка по USB»**. Если есть «Отладка по сети» или
   «ADB по сети», включите и её.

На старых Android TV эти пункты лежат в «Настройки устройства».

**Если подключиться не получается** (на некоторых Google TV 14 порт 5555 закрыт), используйте «Беспроводную отладку»:
1. «Для разработчиков» → **«Беспроводная отладка»** → включить → **«Подключить устройство с помощью кода»**.
2. На экране будут адрес с портом и шестизначный код. На компьютере:
   ```bash
   adb pair 192.168.1.50:37123 123456      # адрес, порт и код с экрана сопряжения
   adb connect 192.168.1.50:41234          # адрес и порт с основного экрана «Беспроводная отладка»
   adb -s 192.168.1.50:41234 tcpip 5555    # открывает обычный порт 5555 для скриптов
   ```

После перезагрузки ТВ порт 5555 снова закроется: для следующего раза повторите `adb connect` и `tcpip`.

### 0.4. IP-адрес телевизора

**Настройки → Сеть и Интернет →** ваша сеть → **IP-адрес**, например `192.168.1.50`. Дальше в командах подставляйте
свой адрес вместо `192.168.1.50`.

### 0.5. Проверка связи и резервная копия

```bash
scripts/backup.sh 192.168.1.50
```

При первом подключении телевизор спросит **«Разрешить отладку?»** — отметьте **«Всегда разрешать с этого
компьютера»** и нажмите **«Разрешить»**. Скрипт сохранит состояние телевизора в папку `backups/`: список приложений
и настройки. Это запись о том, как было; её же делает очистка перед первым изменением.

## Шаг 1. Очистка телевизора

Лишнее отключается партиями. Что входит в каждую, с пояснениями, — в
[`scripts/tcl-google-tv.txt`](../scripts/tcl-google-tv.txt).

| Партия | Что отключает |
|---|---|
| 1 | слежку и аналитику TCL и Google (Samba TV, логи, атрибуцию) |
| 2 | рекламу и промо TCL, тихую установку партнёрских приложений |
| 3 | демо-режим магазина, режим отеля, Alexa, «очистку» TCL |
| 4 | приложения по желанию: Netflix, Prime Video, AirPlay, заставку Google и т. п. |
| 5 | панель TCL на кнопке «Источник» — только после установки лаунчера (шаг 2) |

Запускайте по одной партии и проверяйте телевизор после каждой: кнопку «Домой», вход HDMI, звук, пульт.

```bash
scripts/debloat.sh 192.168.1.50 1
scripts/debloat.sh 192.168.1.50 2
scripts/debloat.sh 192.168.1.50 3
```

**Партия 4 — по выбору.** Скопируйте `scripts/tcl-google-tv.txt` в `my-tv.txt`, откройте копию в любом текстовом
редакторе и удалите из партии 4 строки с тем, чем пользуетесь (например, Netflix). Строку `# Batch 4:` оставьте.
Потом:

```bash
LIST=my-tv.txt scripts/debloat.sh 192.168.1.50 4
```

Список проверен на TCL G08. На другой модели скрипт остановится: часть пакетов там может отвечать за другое
(например, `com.tcl.ttvs` на некоторых TCL обновляет прошивку). Пакеты, которым принадлежит сохранённая сеть Wi-Fi,
скрипт не трогает: их отключение удалило бы эту сеть.

Пакеты, которых нет на вашем телевизоре, скрипт пропускает («нет на этом ТВ»).

Если после партии что-то перестало работать, верните одно приложение (`scripts/restore.sh 192.168.1.50 <пакет>`)
или всё сразу (`scripts/restore.sh 192.168.1.50`).

## Шаг 2. Установка лаунчера

1. **ViMu.** На телевизоре: Play Маркет → **«ViMu Media Player for TV»** → установить.
2. **Лаунчер:**

   ```bash
   scripts/install.sh 192.168.1.50
   ```

   Скрипт скачает последнюю версию с GitHub, установит её и сделает главным экраном. Он отключит стандартный экран
   Google TV и мастер первого запуска, а кнопки пульта отдаст лаунчеру: «Настройки», «Источник» и микрофон
   (голосовой поиск). Если у вас уже есть файл APK: `scripts/install.sh 192.168.1.50 ShowyLauncher.apk`.
3. Нажмите **«Домой»** на пульте — откроется ShowyLauncher.
4. **Партия 5:** панель TCL на кнопке «Источник» больше не нужна, её заменит меню входов лаунчера.

   ```bash
   scripts/debloat.sh 192.168.1.50 5
   ```

5. **Showy.** Выберите любой фильм → откроется экран «Смотреть» с кодом и QR. Отправьте код боту
   [@showybot](https://t.me/showybot) или отсканируйте QR телефоном — экран обновится сам. Сервер выбирается
   шестерёнкой в правом верхнем углу → «Источник фильмов»: «Бесплатный», «РФ и соседи» (PRO) или «Остальной мир» (PRO).
6. **Проверьте пультом:** шестерёнка открывает настройки Android, «Источник» — меню входов, кнопка микрофона —
   поиск, который сразу слушает.
7. **Заставка (по желанию).** Без неё телевизор при простое показывает лаунчер, а потом гасит экран по своему таймеру:

   ```bash
   adb -s 192.168.1.50:5555 shell settings put secure screensaver_enabled 0
   ```

## Шаг 3. Закрыть отладку

Сначала **перезагрузите телевизор** (пока отладка ещё включена) и проверьте, что после загрузки открывается
ShowyLauncher и кнопки пульта работают. Если что-то не так, исправить ещё можно с компьютера.

Отладка по сети не защищена, поэтому потом её лучше выключить:

1. **Настройки → Система → Для разработчиков:** выключите «Отладка по USB» (и «Отладка по сети», «Беспроводная
   отладка»), нажмите **«Отозвать разрешения на отладку по USB»**.
2. Перезагрузите телевизор.
3. Проверьте с компьютера: `nc -vz 192.168.1.50 5555` должен ответить отказом (`refused`) или не дождаться ответа.

Для обновления или отката отладку нужно будет включить снова (шаг 0.3) и разрешить подключение на экране.

## Обновление

```bash
scripts/install.sh 192.168.1.50
```

Новая версия ставится поверх: история просмотров, закладки и привязка Showy сохраняются.

**После обновления прошивки телевизора** часть отключённого может включиться снова, а главный экран — вернуться к
стандартному. Включите отладку и повторите `scripts/debloat.sh 192.168.1.50 safe` (и свои партии) и
`scripts/install.sh 192.168.1.50`.

## Как вернуть всё

```bash
scripts/restore.sh 192.168.1.50                 # всё обратно, лаунчер остаётся установленным, но не главным
scripts/restore.sh 192.168.1.50 com.netflix.ninja   # вернуть одно приложение
UNINSTALL=1 scripts/restore.sh 192.168.1.50     # всё обратно и удалить лаунчер
```

Перед сбросом телевизора к заводским настройкам сделайте полный откат: мастер первого запуска должен быть включён.
Что было отключено с завода, откат не включает (смотрит самую раннюю резервную копию в `backups/`).

**Без компьютера** одно приложение возвращается на самом телевизоре: Настройки → Приложения → Все приложения →
«Показать системные» → приложение → **«Включить»**.

## Если что-то не так

- **«нет связи с …:5555»** — телевизор выключен или в режиме ожидания, IP изменился (посмотрите снова, шаг 0.4),
  отладка выключена, или компьютер в другой сети (гостевой Wi-Fi, VPN).
- **Телевизор ждёт разрешения** — на экране телевизора висит запрос «Разрешить отладку?»: разрешите.
- **«на ТВ стоит лаунчер с другой подписью»** — стоит сборка из другого источника. Удалите её
  (`adb -s 192.168.1.50:5555 uninstall ru.homescreen.tv`) и установите снова; история при этом сбросится.
- **«No route to host» на Mac** — macOS не пускает Терминал в локальную сеть: Системные настройки → Конфиденциальность
  и безопасность → Локальная сеть → включите Терминал (или программу, из которой запускаете команды).
- **Телевизор в гостевой или отдельной сети для «умных» устройств** — компьютер должен быть в той же сети.
- **Запросы «Разрешить отладку?» копятся на экране** — закройте лишние кнопкой «Назад» и разрешите последний.
- **«unauthorized», а запроса на экране нет** — «Для разработчиков» → «Отозвать разрешения на отладку по USB»,
  на компьютере `adb kill-server`, выключите телевизор из розетки на минуту и подключитесь снова.
- **Шестерёнка и «Источник» на пульте перестали работать** (например, после «Остановить» в настройках приложения) —
  нажмите «Домой»: лаунчер сам включит свою службу кнопок. Не помогло — снова `scripts/install.sh`.
- **После партии 5 «Источник» ничего не делает** — `scripts/restore.sh 192.168.1.50 com.tcl.suspension` вернёт панель TCL.
- **Кнопка микрофона открывает Google Ассистента** — снова запустите `scripts/install.sh`.
- **Нужен Google Ассистент** («Ok Google», голосовые команды): пока лаунчер — помощник, с пульта вызывается его поиск.
  Вернуть Ассистента: `adb -s 192.168.1.50:5555 shell cmd role add-role-holder android.app.role.ASSISTANT com.google.android.katniss`.
- **Пустые ряды фильмов** — лаунчер не достучался до TMDB: проверьте интернет на телевизоре.
- **Время на час не то** — лаунчер показывает время по месту, которое определил по сети. Остальные приложения
  живут по часовому поясу телевизора: Настройки → Система → Дата и время.

## Помочь другу удалённо

Проще всего — [Tailscale](https://tailscale.com) на вашем компьютере и на телевизоре друга (есть в Play Маркете):
скрипты тогда работают по его адресу Tailscale. **Никогда не пробрасывайте порт 5555 на роутере в интернет** —
любой сможет управлять телевизором.

## С помощью Claude

[Claude Code](https://claude.com/claude-code) может пройти все шаги сам. Он запускает скрипты, смотрит снимки
экрана телевизора и спрашивает вас перед каждым изменением. В репозитории есть [`CLAUDE.md`](../CLAUDE.md) с
правилами для него.

1. Поставьте Claude Code — инструкция на [claude.com/claude-code](https://claude.com/claude-code). На бесплатном
   тарифе Claude его нет: нужна подписка Pro или выше, или оплата по API через Console (цены —
   [claude.com/pricing](https://claude.com/pricing)).
2. Сами сделайте на телевизоре шаги 0.3 и 0.4: Claude не может нажимать на пульт.
3. Скачайте репозиторий (шаг 0.2), откройте терминал в его папке и запустите `claude`.
4. Напишите ему, например:

   > Установи ShowyLauncher на мой телевизор, IP 192.168.1.50: сначала очистка, потом лаунчер. Действуй по
   > docs/INSTALL.md и спрашивай меня перед каждой партией.

Claude сам поставит ADB, если его нет, и подскажет, когда нужно разрешить отладку на экране или нажать кнопку на
пульте.

**Без подписки** идите по шагам сами, а с вопросами — в обычный чат на [claude.ai](https://claude.ai) (он есть и на
бесплатном тарифе): вставьте туда текст шага и сообщение об ошибке из терминала. Команды за вас он не запустит, но
объяснит, что не так.
